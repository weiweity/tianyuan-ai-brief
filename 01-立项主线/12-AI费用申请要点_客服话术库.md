# AI 费用申请要点 · 客服话术库（MVP-A）

> 配套：同目录 `11-立项卡_客服话术库_一页纸.md`（`01-立项主线/`）  
> 用途：费用/采购沟通；**先定科目与必要性，金额由财务/供应商报价回填**  
> 状态：软件未开发 · 申请服务于立项启动

---

## 1. 申请一句话

申请 AI 相关费用，用于建设 **客服话术库 MVP-A**（知识库+问答 + 意图/检索推荐快捷语），支撑外包背景下的标准答法统一；**不做自动代回**。

---

## 2. 为什么现在要钱（业务）

| 点 | 说明 |
|----|------|
| 时机 | 客服转外包 + 无内网 → 标准必须工具化，否则口径漂 |
| 调研结论 | 多部门摸底后，此项最适合作为 AI 组 **首个可立项样板** |
| 不做的代价 | 继续靠个人文档；外包质量难治理；后续培训/质检无地基 |

---

## 3. 首期花在哪（科目）

| 序号 | 科目 | 必要性 | 预估金额（量级占位） | 备注 |
|------|------|--------|----------------------|------|
| 1 | 大模型 / API 调用费 | 问答与意图理解 | **数百～数千元/月**（精确数 **48h 财务回填**） | **必须**月度 cap；超 cap 停扩调用 |
| 2 | 应用托管 / 服务器 / 内网部署 | 内部可访问 | 并入首期小计量级 | 与 IT 口径对齐 |
| 3 | 检索/向量等相关组件（若需要） | 语义匹配 | 可与复用底座合并 | 优先复用 wording |
| 4 | 其他（域名、证书、存储等） | 视方案 | 视方案 | |
| | **MVP-A 首期小计** | | **万元内可停损**（精确数待填） | 仅 MVP-A；L3/L4 另立 |

**库规模（控费与质量）：** 首期导入建议限试点场景精选（量级 ≤500 条，G0 与 Owner 共定），避免无主数据灌库拖垮检索与标注成本。

**明确二期再议（本期可不报或单列可选）：** 桌面端嵌入（L4）、外包全量环境、质检专项。

## 4. 费用与交付挂钩（给审批人吃定心丸）

| 里程碑 | 费用使用 | 可停损 |
|--------|----------|--------|
| 立项批准 | 启动环境与最小调用 | 不批则 0 支出 |
| MVP-A 可演示 | 开发期调用 + 托管 | 演示不过可停扩面 |
| 内部小范围试用 | 试用期调用 | 无采用则不进 L3/L4 追加预算 |

---

## 5. 不批 / 少批时的降级方案

| 情景 | 降级 |
|------|------|
| 不批模型费 | 仅做结构化话术库 + 关键词检索（无智能问答） |
| 不批托管 | 仅方案与本地 Demo，不承诺业务试用 |
| 只批极少额度 | 缩到单场景话术包 + 人工维护，验证流程后再扩 |
