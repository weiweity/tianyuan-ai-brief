## Architecture（工程读立项）

### 修正后的产品分层

```
L1 知识库 + 问答 + 【管理端改库生效】  ← MVP-A
L2 意图/检索推荐快捷语                 ← MVP-A
L3 全员推送 / 过期提醒 / 版本·审批     ← 二期（不再叫笼统「统一更新」）
L4 桌面聊天嵌入                         ← 二期/三期
```

### MVP-A 系统边界（6A）

```
                    ┌─────────────────────────────────────┐
  话术真源 Owner    │  管理端（改库 → 即时生效）            │
       │            └──────────────┬──────────────────────┘
       ▼                           ▼
  ┌──────────┐              ┌─────────────┐     可选
  │ 话术库   │◄────────────│ 检索 / 轻LLM │◄── 外网 API
  │ (复用底座│              └──────┬──────┘     (有 cap)
  │ +缺口)   │                     │
  └──────────┘                     ▼
                    ┌──────────────────────────┐
  内部坐席 ────────►│ 内网 Web 入口              │
                    │ 推荐文案 → 人复制 → 聊天工具│
                    │ （不代发、不嵌桌面客户端）  │
                    └──────────────────────────┘

  明确不在边界内：自动代回、L4 嵌入、质检、外包专网、供应链系统
```

### 门禁（加固后）

```
① 调研 ✅
② 立项/费用路径  ← 当前（金主 A/B/C）
   │
   ▼ 仍可批「方向」
③ Scope 冻结 —— 前置必须：
   [ ] 话术真源 Owner 具名
   [ ] 客服负责人原则同意
   [ ] wording 复用盘点表（能/不能/缺口）
   [ ] 系统边界图确认
   [ ] （G0）数据出域/脱敏原则
   │
   ▼
④ 分阶段交付 MVP-A …
```

### 工期语义（5A）

- **D0** = 立项+费用路径批准日  
- **6–8 周** = **可用工作周**（出差/全职旁线周不计入或单独加注）  
- 供应链上海会等 **不计入本立项成功标准**

## 可测成功标准（8A · 数量级可 G0 改数）

| # | 门槛（暂定） | 失败即不宣称 MVP-A 成功 |
|---|--------------|------------------------|
| 1 | 有效话术 ≥ **200** 条（或业务共定 N），含分类 + Owner 字段 | 空库/无主数据 |
| 2 | **20** 条黄金问法，人工标期望话术，Top3 命中 ≥ **70%** | 检索不可用 |
| 3 | ≥ **3** 名内部坐席，连续 **2** 周，每人每周真实检索 ≥ **5** 次 | 无采用 |
| 4 | 抽检 **0** 次系统自动代发（人在环 100%） | 越界代回 |
| 5 | 管理者改一条 → **同日**坐席侧可检索到新内容 | L1 改库未生效 |

## 软件工程视角 · 对立项逻辑的总判

**做得对的：**

1. **阶段诚实** — 停在 ②，禁止跳关「试点/上线」话术  
2. **切片** — MVP-A 只背 L1+L2，费用与里程碑挂钩可停损  
3. **不做清单** — 代回/质检/设计主 R 挡需求，符合 blast-radius  
4. **双轨自觉** — 主 R vs 布局，方向正确（本轮补成书面工期语义）  
5. **组织门禁意识** — 企业内部先批再做，不是互联网先发再补  

**本轮修掉的工程债：**

1. L1/L3 验收口径打架  
2. 成功标准不可测  
3. 复用 vs 重建未写死  
4. Owner 非门禁  
5. 无系统边界图 / 无评测模板 / 无费用 cap  

**仍依赖人的判断（工程锁不死）：** 金主 A/B/C、客服原则同意、财务填金额、底座盘点结果。

**一句话：**  
立项逻辑在 **流程与政治** 上已经专业；在 **可交付工程规格** 上原先偏薄。按本轮拍板回写后，这份立项才从「叙事正确」升级为「批了能交、交了能判」。
