## 2. 交互方向：要不要大改？

### 保持（正确决策）

1. **Tab = 汇报章节**，不是无限长滚动一页——符合 12–15′ 口播节奏。  
2. **内容 JSON 与壳分离**——防越改越乱。  
3. **左右滑翻页**——手机客户浏览的正确隐喻（类故事/PPT）。  
4. **竖滑优先于横滑阈值**——避免看表时误翻页。

### 建议微调（已做 / 可选）

| 项 | 状态 | 说明 |
|-|-|-|
| 手机工具栏收纳 | ✅ 已做 | 「⋯」菜单，减少顶栏噪声 |
| 页码点 + 边缘‹› | ✅ 已做 | 降低「不知道有几页」 |
| 滑动提示文案 | ✅ 已做 | 首屏可理解 |
| 首访仅展示一次引导遮罩 | 可选 | 现用底栏 hint，够用 |
| 勾选表手机改为「卡片列表」 | 可选 P2 | 进一步降密度 |
| 暗色投屏模式 | 可选 | 会议室灯光场景 |

**总判：交互方向不需要推倒重来。** 维持「章节 Tab + 一屏舞台 + 触屏翻页」即可。
