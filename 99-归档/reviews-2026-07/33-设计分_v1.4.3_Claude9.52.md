## 无感保存 / C 端自动刷新（大厂逻辑）

### 编辑者
1. 点 **编辑** → 改字  
2. 点 **保存并更新**（仅一次主按钮）  
3. 系统：收割 DOM → 写 content.json（已绑定则静默）→ **softApply 热刷新本页**（保留当前 Tab，轻闪，不整页 reload）  
4. 写盘失败：本页仍预览更新，**保留编辑态**可再点保存  

### 浏览客户（分享链接）
- 打开即拉最新 content.json（`cache: no-store` + 时间戳）  
- **不读**编辑草稿，避免看到未发布内容  
- 每 **30 秒** / 切回前台：比对 `version|updated|publishStamp`  
- 有变化 → **自动 softApply**，Toast「内容已自动更新」  
- 弱网连续失败 3 次 → 提示，恢复后继续同步  

### 发布到公网
```bash
git add docs && git commit -m "content: …" && git push
# 客户端约 30s 内自动看到
```
