## 本地打开软件

```bash
cd web-decision-brief
npm install
npm run serve
```

打开 `http://localhost:8765`。在线 Pages 可能仍是上次发布的旧稿，不能替代本地业务真源。

> **防丢失提醒：** 本仓库有本地排除和未跟踪文档。交接或换电脑前先看[驾驶舱的“防丢失与交付风险”](business-docs/00-项目驾驶舱.md#7-防丢失与交付风险)，不要把“本机能打开”等同于“Git 已备份”。
