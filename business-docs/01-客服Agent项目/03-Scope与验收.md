## B. 黄金问法评测表（空表 · 目标 20 条）

### B.1 分层覆盖规则

- G0 必须先冻结“试点平台 × 核心场景”覆盖矩阵，并为每个正 / 负例标注唯一分层；
- 20 条正例中，每个确认进入 Scope 的平台 × 核心场景至少 2 条，其余按现状任务频次分配；单一分层不得超过 40%，除非基线证明其真实占比 ≥40% 并附证据；
- 至少 5 条负例必须覆盖：无依据、过期 / 冲突、无权限 / 敏感、意图模糊需追问、超范围需转人工；高风险分层至少有 1 条负例；
- 汇总指标与每个分层的样本数、Top3 命中、引用 / 版本正确和错误直答必须同时报告；缺分层或只报总分不得验收。

### B.3 统一计分与防过拟合规则

1. 业务标注人在看到系统输出前冻结可接受话术 ID 集；实现者不得在验收当天补答案。
2. G1a 使用 20 条正例 **全量**计分，不允许“业务抽样”、删除难题或只报成功案例。
3. `Top3 命中率 = Top3 命中题数 / 20`；并列结果按系统实际展示顺序取前三。
4. 任何未发布、已过期、平台不适用或引用版本错误的话术，按未命中计。
5. 负例错误直答、自动代发、越权泄露任一 `>0`，本轮直接不通过。
6. 调参开发集与冻结验收集必须分开；若冻结集或内容快照变化，生成新版本并整集重测。
7. 同一冻结集同时测关键词基线和候选方案；语义 / 模型无可解释增益时，默认采用成本更低、风险更小的方案。

**G1a 暂定门槛：** 总体正例 Top3 ≥ **70%**；每个已冻结分层 Top3 ≥ **50%** 且至少命中 1 条；总体及各分层引用 / 版本正确率 = **100%**；负例错误直答 = **0**。任一分层未达线即失败，不能用总体均值抵扣。阈值可在 G0 依据基线提高；如需降低，必须有真实任务基线、业务 Owner 与 QA 双签及 DEC，且不得取消“每层至少 1 命中”和分层否决。
