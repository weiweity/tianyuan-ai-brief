## 4. 费用与交付挂钩

| 阶段 | 可以发生的费用 | 停止条件 |
|------|----------------|----------|
| 设计阶段 / G0 | 只做测算、合同 / 空模板 / 纯合成 fixture 与本地静态验证；外部 teacher 调用为 0 | B 路径已签；任何新增付费或外部 teacher 调用都会立即停止并重新审批 |
| 一期可演示 | 只按已批准上限用于一期检索与人在环闭环验证；不做真实训练或外部 teacher 批次 | 核心流程不通或安全不满足则停止扩面 |
| 3–5 名坐席灰度 | 只承担最小真实试用成本 | 无提效、错误上升、稳定性不达标则停止 |
| 后续扩面 / 二期 / 三期 | 必须重新核对人数、并发、数据治理、Agent 范围与总成本 | 未形成新的批准记录不得扩面或建设 Agent |

## 5. 不批 / 少批时的降级方案

| 情景 | 仍可怎么做 |
|------|------------|
| 不批模型费 | 用规则、关键词或人工流程先跑通最小闭环 |
| 不批托管 | 只做脱敏样本和本地演示，不接真实业务 |
| 只批极少额度 | 缩到一个任务、一个平台、3–5 名坐席验证 |

降级后仍要记录真实效果，不能把“做出了页面”当作业务成功。
