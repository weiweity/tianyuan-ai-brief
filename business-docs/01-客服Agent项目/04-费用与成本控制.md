## 1. 申请一句话

申请 AI 相关费用，用于建设 **客服 Agent 首期话术库 MVP-A**（知识库、内容治理、问答与意图 / 检索推荐），支撑外包背景下的标准答法统一；**不做自动代回**。

## 2. 为什么现在要钱（业务）

| 点 | 说明 |
|----|------|
| 时机 | 客服转外包 + 无内网 → 标准必须工具化，否则口径漂 |
| 调研结论 | 多部门摸底后，此项最适合作为 AI 组 **首个可立项样板** |
| 不做的代价 | 继续靠个人文档；外包质量难治理；后续培训/质检无地基 |

## 5. 不批 / 少批时的降级方案

| 情景 | 降级 |
|------|------|
| 不批模型费 | 仅做结构化话术库 + 关键词检索（无智能问答） |
| 不批托管 | 仅方案与本地 Demo，不承诺业务试用 |
| 只批极少额度 | 缩到单场景话术包 + 人工维护，验证流程后再扩 |
