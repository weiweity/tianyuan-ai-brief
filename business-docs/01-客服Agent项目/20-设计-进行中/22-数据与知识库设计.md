# 客服 Agent 一期 · 数据与知识库设计

> **状态：** DRAFT
> **目标：** 把分散话术变成可查询、可更新、可下架、可追溯的受控内容

## 一期最小数据对象

| 对象 | 必填字段 |
|------|------------|
| 话术条目 | 脱敏 ID、标题、正文、内容类型、状态 |
| 适用范围 | 平台、商品 / SKU 范围、活动类型、用户条件、地区 / 渠道 |
| 时间范围 | 生效时间、失效时间、发布时间、下架时间 |
| 来源与版本 | 权威源 ID、源版本、内容版本、内容哈希 |
| 治理责任 | 维护角色、审核角色、最后复核时间、下次复核时间 |
| 冲突与替代 | 优先级、被替代版本、冲突组、裁决状态 |

## 内容生命周期

```text
原始来源
  → 清洗与拆分
  → 适用范围标注
  → 内容复核
  → 发布版本快照
  → 检索索引
  → 使用与反馈
  → 修订 / 下架 / 回滚
```

任何时候只能有明确的已发布版本进入坐席查询。过期、冲突未裁决、超出适用范围或无权限的内容不得生成可直接采用的答案。

## 为二期语料库蒸馏预留

一期只记录可控、可脱敏的学习信号：

- 脱敏问题类型与必要上下文；
- 系统候选及引用证据；
- 坐席采用、修改、拒绝、澄清或升级的结果；
- 修改差异的结构化标签，不默认保存完整客户对话；
- 话术版本、适用范围和最终业务确认。

二期再经数据清洗、权限复核、语料蒸馏和稳定性测试形成训练 / 评测语料库，一期日志不自动等于可训练数据。
