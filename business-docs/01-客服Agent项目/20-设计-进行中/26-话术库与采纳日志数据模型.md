# 话术库字段 · 采纳日志 · 迭代提醒

> **状态：** DRAFT v1.0 · 2026-08-05  
> **配套 PRD：** [`25-PRD草案-客服Agent一期.md`](25-PRD草案-客服Agent一期.md)  
> **边界：** 一期 **只选不改字**；日志用于训库与提醒话术师，**不自动改 Answer 正文**  
> **公开仓：** 无真实姓名、无客户原文样例

## 1. 两套数据各干什么

| | **话术库（资产）** | **采纳日志（流水）** |
|--|-------------------|---------------------|
| 存什么 | Q-A、分类、版本、是否可推 | 某次查询推了啥、人选了啥 |
| 谁写 | 话术师为主 | 系统自动 |
| 用途 | RAG 检索、发布口径 | 迭代提醒、训 Question、查算法问题 |

```text
话术库 ──检索──► Top3 ──坐席选用──► 采纳日志
   ▲                                    │
   └──── 话术师根据「迭代工单」改库 ◄───┘
```

## 2. 话术库字段表

### 2.1 话术条目 `script`（Answer 主实体）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `script_id` | 稳定 ID | 是 | 业务主键，日志外键 |
| `category` | 枚举 | 是 | `presale` 售前 / `campaign` 活动 / `aftersale` 售后 / `product` 产品 |
| `title` | 短文本 | 是 | 列表用标题 |
| `answer_text` | 长文本 | 是 | **标准话术正文；一期推送必须原样** |
| `status` | 枚举 | 是 | `draft` / `in_review` / `published` / `archived` |
| `version` | 整数或 semver | 是 | 发布递增 |
| `content_hash` | 哈希 | 是 | 正文变更检测 |
| `platform_scope` | 多选 | 建议 | 千牛/抖音/通用等 |
| `sku_scope` | 文本/列表 | 否 | 适用商品范围 |
| `campaign_tag` | 文本 | 否 | 活动标识 |
| `effective_from` | 时间 | 建议 | 生效 |
| `effective_to` | 时间 | 建议 | 失效；过期不得进 Top3 |
| `priority` | 数 | 否 | 冲突时参考 |
| `owner_role` | 角色代号 | 是 | 维护责任 |
| `reviewer_role` | 角色代号 | 建议 | 复核 |
| `source_ref` | 文本 | 否 | 权威来源备注（无外链明文） |
| `created_at` / `updated_at` / `published_at` | 时间 | 是 | 审计 |
| `supersedes_script_id` | ID | 否 | 替代旧版 |

**规则：** 仅 `published` 且在有效期内可被推荐。

### 2.2 问法 `script_question`（Question）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `question_id` | ID | 是 | |
| `script_id` | FK | 是 | 挂到哪条 Answer |
| `question_text` | 文本 | 是 | 典型问法；**初期人工写** |
| `source` | 枚举 | 是 | `manual` 人工 / `from_log` 日志沉淀 / `import` 导入 |
| `status` | 枚举 | 是 | `active` / `disabled` |
| `created_by_role` | 角色 | 否 | |
| `created_at` | 时间 | 是 | |

一条 Answer 可挂多条 Question。RAG 主要用 Question + Answer 建索引。

### 2.3 可选：分类扩展（一期可后置）

| 字段 | 说明 |
|------|------|
| `intent_tag` | 意图标签（退货、发货、成分…） |
| `risk_level` | 低/中/高（高风险不得低置信直推） |

| `latency_ms` | 数 | 否 | |
| `model_trace_id` | 文本 | 否 | RAG/DeepSeek 追踪 |
| `created_at` | 时间 | 是 | |

### 3.2 候选曝光 `candidate_impression`（每条 Top 一行）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query_id` | FK | 是 | |

### 3.3 选用结果 `adoption_event`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query_id` | FK | 是 | |
| `outcome` | 枚举 | 是 | `adopted` 选用 / `dismissed` 全不用 / `no_hit_exit` 无结果离开 / `timeout` |
| `chosen_rank` | 1–3 / 空 | 条件 | 选了第几 |
| `chosen_script_id` | FK / 空 | 条件 | |

| `created_at` | 时间 | 是 | |

**一期最小必采：** `query` + 最多 3 条 `impression` + `adoption`（有无选用、选了 rank 几）。

## 4. 话术自动识别迭代（提醒话术师）

### 4.1 产品目标

系统根据日志 **自动聚类问题、发现异常**，生成 **迭代工单** 提醒话术师：

- 可能是 **话术库缺口**（该补 Q 或 A）  
- 也可能是 **排序/算法问题**（库里有，但 Top1 总不对）  

**一期不自动改 Answer**，只 **提醒 + 建议动作**；改库仍由话术师完成。

### 4.2 信号规则（建议默认阈值，可配置）

| 信号 ID | 名称 | 触发条件（示例） | 更像什么问题 | 建议动作 |
|---------|------|------------------|--------------|----------|
| SIG-NO-HIT | 无命中聚集 | 同 `query_text_hash` 或同意图簇，**无命中 ≥ N 次 / 窗口 T**（如 7 天 ≥ 5） | **库缺口** 或缺 Question | 补 Question 或新建 Answer |
| SIG-SKIP-TOP1 | 常跳过 Top1 | 有 hit 且选用，**chosen_rank≥2 占比 ≥ P**（如 ≥40%）且样本 ≥ M | **排序/算法** 或 Top1 口径差 | 检查 score；或调整 Question 挂接；或修订 Top1 话术 |
| SIG-ALWAYS-TOP2 | 稳定选 Top2 | 同簇多次选用 **同一 script 且 rank=2** | Top1/Top2 **挂错 Q** 或排序反了 | 对调优先级 / 重挂 Question |
| SIG-LOW-ADOPT | 有曝光不选用 | hit 后 `dismissed` 占比高 | 推荐不准或场景不对 | 复查 Answer 是否过期/错类 |
| SIG-CAT-MISMATCH | 类型疑似错 | 检测类型与选用 script.category 不一致多 | 分类/算法 | 纠分类或过滤规则 |

> 阈值 N/T/P/M 在 G0 前与业务拍一版默认值即可，后续可调。

### 4.3 迭代工单 `iteration_ticket`

| 字段 | 说明 |
|------|------|
| `ticket_id` | |
| `signal_id` | 上表 |
| `cluster_key` | 问法簇（hash 或意图） |
| `sample_query_ids` | 抽样日志 |
| `suspected_cause` | `content_gap` 库缺口 / `ranking` 算法排序 / `stale` 过期 / `mixed` 待判 |
| `suggested_script_ids` | 相关话术 |
| `status` | `open` / `in_progress` / `resolved` / `wont_fix` |
| `assignee_role` | 话术师 |
| `resolution_note` | 已补 Q / 已改 A / 已调权重 / 忽略原因 |
| `created_at` / `resolved_at` | |

### 4.4 话术师工作流（UC-ITER）

```text
定时/准实时扫描日志
  → 命中信号 → 生成/合并迭代工单
  → 飞书或 App 内提醒话术师
  → 话术师打开：看样例问法 + Top 曝光 + 选用分布
  → 选择：补 Question / 改 Answer / 标记「算法侧处理」/ 关闭
  → 发布后索引更新；工单 resolved
```

**区分责任（界面上写清）：**

| 判定 | 谁处理 |
|------|--------|
| 无命中、缺问法 | **话术师** 补库 |
| 总有库、总不选 Top1 | 先看 **排序**（工程）+ 话术师看 **Top1 是否该换** |
| 过期仍进 Top | **工程过滤 bug** 或生效时间填错 |

### 4.5 一期 MVP vs 增强

| 能力 | 08-12 / 一期 MVP | 完整一期 |
|------|------------------|----------|
| 记 query + top3 + 选用 rank | 必须 | |
| 无命中列表给话术师 | 必须 | |
| 「常跳过 Top1」统计 | 建议 | 必须 |
| 自动聚类 + 飞书推送工单 | 可后置 | 建议 |
| 自动改库 | **不做** | **不做** |

## 5. 隐私与合规要点

- 日志中的客户原话 **脱敏**；保留期、出域（DeepSeek）走安全批  
- 聚合优先用 `query_text_hash` + 抽样审核  
- 迭代工单展示给话术师的样例须权限控制
