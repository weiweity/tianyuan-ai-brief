## 1. 一句话与一期目标

Dashboard 是 coach / owner 的运营与治理工作台。一期在同一入口提供：

1. 工具使用概览、根问题 / 操作双账、检索 / 复制自动事实流水与离线三维抽样复核；
2. **业务工单分析**：批准的 CSV/XLSX 导入、校验、聚合、筛选、下钻与脱敏导出；
3. **话术优化待办**：处理无命中、跳过 Top1 等内部质量信号；
4. 内容 Import → Publish → Announce 与客户端同步状态。

它不是经营数据真相源，不在页面直接编辑话术正文，也不写回班牛。

CR-002 只扩展第 1 项的检索流水，不替换本 Dashboard 顶层信息架构，也不影响 CR-001 `work_order_*` 工单分析。

## 2. 用户、角色与最小权限

| 角色 | 可读 | 可写 / 可执行 | 禁止 |
|------|------|---------------|------|
| `agent` | 自己的必要状态；浮窗为主 | 无 Dashboard 管理动作 | 访问工单明细、批量导出、关单、发布 |
| `coach` | 工具指标、授权范围流水、工单聚合 / 明细、话术优化待办 | 导入工单文件、处理待办、发起内容导入 | 发布内容、越域查看、修改话术正文 |
| `owner` | 全部授权业务范围 | coach 能力 + Publish / Rollback / 分析导出 | 绕过审批、修改原始审计、写回班牛 |

Mock 登录仅限开发 / 演示，页面必须显示 `DEMO / MOCK AUTH`。试点和生产必须使用真实飞书 OAuth、服务端会话与 RBAC。

样本审核、业务复核、数据安全复核、技术排障等新增权限统一作为既有 `agent / coach / owner` 身份上的**最小 capability**，不建立可绕过现有业务角色的平行角色。业务与数据安全双审分别留证；agent 无 Dashboard 管理权限。

## 3. 信息架构

```text
Dashboard
├─ 概览与工具指标
├─ 检索 / 复制自动事实流水
│    ├─ 根问题账 / 操作账（默认聚合、无个人排名）
│    ├─ 优化层（无命中 / 放弃 / 升级 / 重选 / Top1 跳过）
│    └─ 受权下钻层（脱敏问法—话术配对；访问留审计）
├─ 离线三维抽样复核（修改 / 发送 / 适用性分账）
├─ 工单分析              （业务导出数据）
├─ 话术优化待办          （内部改进）
├─ 内容导入、四域来源绑定与发布
└─ 公告、同步与离线租约状态
```

导航文案不得用单独的“工单”指代两类对象。页面标题、面包屑、空态、导出文件名和审计事件都必须保留完整名称。

## 4. 概览与检索 / 复制流水

### 4.1 指标口径

| 指标 | 口径 | 数据源 |
|------|------|--------|
| 复制率 | `count(outcome=adopted) / count(hit_status=hit)` | 中心 SoR 兼容事件；`adopted` 只表示 `push_method` 成功 |
| 无命中率 | `count(hit_status=no_hit) / count(query)` | 中心 SoR 事件 |
| Top1 复制占比 | `chosen_rank=1 / adopted` | 中心 SoR 事件 |
| 根问题 / 操作数 | parent 链去重根问题 / 全部合法 query 操作 | `parent_query_id + attempt_kind=original|reselection`，两账不得混用 |
| 抽样复核覆盖 | 已复核根问题 / 冻结抽样池 | 三维分层规则、样本量、不可核验和证据等级同时展示 |
| 修改 / 发送 / 适用性 | 三个结论分别 / 各自已完成复核分母 | 不从复制推断；`unverifiable` 分列 |
| 弱升级率 | `escalate_action / no_hit` | 中心 SoR 事件 |
| P95 查询延迟 | 查询事件延迟的 P95 | 中心 SoR 事件 |

响应时间、满意度、转化率属于平台后台经营指标；除非已有批准的数据集成与口径，不得在本页造数或拼接成“经营提升”。复制不得命名为“实际采用”或“回答正确”；修改、发送与适用性只来自 G1b / Pilot 协议下的授权离线三维抽样 EVD。

### 4.2 流水

- `query_id` 从浮窗贯通到曝光、复制、放弃、升级和错误；重选新建 query 并用 `parent_query_id + attempt_kind` 归根；
- 默认仅展示脱敏问法，不展示未批准客户原文；
- 支持时间、canonical `platform`、命中、复制位次、操作终态、内容版本筛选；Phase 1 的 `platform` 必须经用户确认：直接手选/修正=`manual`，接受一次性 `detected_platform` 提示=`foreground_process`；提示本身不自动成为真源；
- 每行可展开 Top3、`release_id/script_id/script_version/content_hash`、`push_method` 兼容值和操作终态，不提供最终发送正文入口；
- 无权限、数据延迟或口径缺失时明确显示原因，不用 `0` 替代未知。
- `collection_disabled/stateless` 会话不得进入指标、流水正文或语料候选；页面须显著显示“本次仅安全搜索，未采集证据”。DLP、Auth、内容不就绪仍显示阻断状态。

## 5. 工单分析（业务导出数据）

### 5.1 一期边界

| In | Out |
|----|-----|
| 手工上传批准的 CSV/XLSX | 班牛实时 API 默认接入 |
| 文件与字段预检、显式映射 | 自动建单、填单、改单或回写 |
| 标准化记录的聚合、筛选、排序、下钻 | 未批准原始文件长期保存 |
| 脱敏分析结果导出与完整审计 | 原始工单默认出域到第三方模型 |

CR-001 已登记“一期方向=导出工单分析”，但正式启用真实数据仍以字段白名单、保留期、安全批准、书面 EVD 和 G0/Ddev 为门禁。

### 5.2 导入流程

```text
选择文件
  → 本地基础校验（扩展名 / 大小）
  → 服务端预检（表头 / 类型 / 必填 / 重复 / 敏感字段）
  → 用户确认字段映射与数据口径
  → 创建 import_batch
  → 标准化入库
  → 聚合可用
```

导入批次必须显示：`import_batch_id`、文件名的安全摘要、数据日期范围、来源系统、记录总数 / 成功 / 拒绝数、映射版本、操作者代号、状态、创建 / 完成时间。错误行下载必须脱敏并受权限控制。

### 5.3 标准筛选与分析

一期至少支持以下**白名单字段**；实际启用前由业务与安全签字，未列字段不得静默入库：

- 工单类别、问题类型、商品 / SKU 脱敏标识、渠道、状态；
- 创建 / 完成日期与计算后的处理时长；
- 错误类型、是否升级、质量标签；
- 数据批次与标准化版本。

至少提供：总量、类别 / 问题分布、质量错误分布、处理时长分布、趋势、筛选后的明细下钻。每个图表必须显示批次、筛选条件、口径与刷新时间。

### 5.4 导出

- 只导出当前筛选范围内的批准字段；
- 文件名包含生成时间和批次短标识，不含客户、订单或工单原编号；
- 导出前显示记录数与字段清单，导出后记录审计；
- 超出阈值、跨业务范围或含敏感字段时拒绝并返回可执行原因。

## 6. 话术优化待办（内部改进）

来源仅限搜索 / 复制兼容流水中的无命中、跳过 Top1、稳定复制 Top2、低复制、分类疑似错误等信号。数据对象统一为 `iteration_task`。

| 能力 | 一期行为 |
|------|----------|
| 列表 | 按状态、信号、责任角色、创建时间筛选 |
| 详情 | 脱敏样例、曝光与选择分布、疑似原因、建议话术 |
| 流转 | `open → in_progress → resolved / wont_fix`；服务端校验并发版本 |
| 动作 | 开始处理、填写处理结论、关闭；发布动作仍走内容管线 |
| 禁止 | 自动改 Answer、把业务工单明细挂到待办、绕过内容复核 |

同一信号可合并到现有待办，但必须保留来源样本引用和状态变更审计。关闭待办不等于内容已发布；如涉及改库，必须关联对应 release。

## 7. 内容导入、发布与公告

- Dashboard 可触发导入校验、查看 staging 差异、由有权 owner Publish / Rollback；
- 话术正文仍在批准的飞书 / Excel 源维护，Dashboard 一期 **零写正文**；
- 每个候选 release 必须展示售前 `presale`、活动 `campaign`、售后 `aftersale`、产品 `product` 四域各自绑定的不可变 `use_class=canonical` 来源版本；未登记、`reference`、四域缺一/重复、hash / EVD 不匹配或任一版本已有暂停记录时，导入、发布、回滚与检索状态均显示硬阻断；
- `canonical/current` 不设人工开关：页面只根据 `content_current` 所指 release 及其四域 binding 展示。暂停是只追加事实；旧来源版本一经暂停永久不可恢复，恢复业务必须登记新版本并发布新 release；
- 导入向导不得提供“文件内 `source_ref` 覆盖权威来源”的能力。文件行含来源自报字段时整批拒绝；来源版本只能由服务端从受信导入上下文附加；
- “切换来源并发布”是一个原子动作：成功时新 release、四域绑定、current 指针、公告与审计一起可见；任一步失败时旧 current 保持不动，不展示半切换；
- Rollback 前重新校验目标 release 的四域绑定与全部暂停记录；命中永久暂停或绑定不完整时整次拒绝，禁止过滤部分内容后标记“回滚成功”；
- Publish 成功后生成 release，Announce 后客户端通过 snapshot / ACK 同步；服务端签发短租约，ACK 只确认同步游标且不续租；离线客户端租约到期后必须停止本地检索并提示联网同步，不得继续使用过期快照；
- 页面必须区分 `validated`、`published`、`announced`、`client acknowledged`，不得用一个“已同步”混合表示。

## 8. 全局状态、错误与审计

### 8.1 状态

所有模块都必须有：加载中、无数据、无权限、部分失败、数据过期、服务不可用和成功状态。Seed / 合成数据必须持续显示 `DEMO DATA`，不能只在首次进入时提示。

### 8.2 错误

- 展示可读原因、追踪 ID 和重试动作；不向前端暴露堆栈、SQL、内部路径或原始敏感值；
- 429 显示稍后重试；503 显示服务暂不可用；冲突流转显示“数据已被他人更新，请刷新”；
- 导入部分成功必须给出成功 / 拒绝数，不得整体显示绿色“完成”；
- CR-004 的来源未登记/仅供 reference、来源缺失或不匹配、永久暂停、租约到期都必须与普通“无命中”分开显示；禁止用空结果掩盖治理拒绝。

### 8.3 审计

至少审计：登录身份、受权脱敏样本查看、离线抽样规则与复核结论、语义资产业务 / 数据安全双审、工单文件导入 / 映射 / 查询 / 导出、待办状态变更、内容导入 / 发布 / 回滚、四域来源绑定 / 暂停拒绝、公告、租约与同步确认。审计记录只追加，不允许 Dashboard 删除或改写；审计不得复制 raw 客户问法、最终发送正文、内部存储路径或 token。

CR-004 拒绝审计必须在失败业务事务回滚后，以独立、幂等的最小事务提交；不得把审计 INSERT 与随后抛错放在同一回滚事务内。若拒绝审计自身无法持久化，管理写动作继续 fail-closed，并显示可追踪的系统错误，不得假装已审计。

## 9. 一期验收合同

1. agent 无法访问 Dashboard 管理接口；coach / owner 权限矩阵生效；
2. 同一 `query_id` 可从概览下钻到完整脱敏流水；指标分母与时间窗可见；
3. 工单样例完成“预检 → 映射 → 入库 → 聚合 → 下钻 → 脱敏导出”，非法字段、重复导入、超限与越权均被拒绝；
4. 工单分析全链路没有班牛写回、自动填单和未经批准的原始数据出域；
5. 话术优化待办可以查看来源、开始、关闭，并拒绝非法状态跳转；其 ID / 表 / API 与 `work_order_*` 完全分离；
6. Dashboard 无话术正文编辑入口；发布、公告与客户端 ACK 状态可区分；
7. Mock 身份和 seed 数据在演示中明确标识；试点构建检测到 Mock 时必须阻断；
8. 所有写动作和导出均有操作者、时间、对象、结果、追踪 ID 审计。
9. 浮窗不设置强制结果自报；Dashboard 将自动事实与离线三维复核分账，修改 / 发送 / 适用性不可核验时明确显示 `unverifiable`。
10. telemetry 故障可降级为 `collection_disabled/stateless` 安全搜索并排除指标 / 语料；DLP、Auth、内容不就绪仍 fail-closed。
11. G1a 的 `20+12+18`、G1b REAL-FWD 与 train manifest 分区展示，按语义簇 / lineage / 模板祖先零交集，不得相互补样或合并分母。
12. 一期训练页只显示 schema / 空模板 / 纯合成 fixture 状态；无真实晋级、教师调用、训练或模型发布入口。
13. 每个 release 恰好展示四域不可变来源绑定；canonical/current 只能由 current release 推导，不存在可变来源开关。
14. 任一来源版本被追加暂停记录后永久不可重新导入、发布、回滚或检索；恢复业务只允许新来源版本 + 新 release。
15. 导入文件行自报 `source_ref`、使用未登记或 `reference` 来源、四域绑定缺失/重复/不匹配、发布或回滚命中暂停来源时，整步拒绝且旧 current 不变。
16. 来源切换、release、四域绑定、current、announcement 与 change audit 同成同败；拒绝审计在失败事务之外独立、幂等提交。
17. 离线短租约到期后客户端停止本地检索；页面显示“需联网同步”，不得把过期快照继续作为 no-hit / 正常结果。
