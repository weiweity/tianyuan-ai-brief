## 1. 产品形态

```text
Windows Electron 壳
├─ 浮窗（一线）→ 写检索 / 候选 / 复制 / 放弃 / 升级 / 重选自动事实
└─ Dashboard（coach/owner）
     ├─ 概览与根问题 / 操作双账、自动事实流水
     ├─ 离线三维抽样复核
     ├─ 工单分析（业务导出数据）
     ├─ 话术优化待办（内部改进）
     ├─ 内容导入与发布
     └─ 公告与同步状态
中心 API + PostgreSQL SoR
内容：受信来源版本 → Import → Publish(release + 四域不可变绑定) → Announce/短租约 → 全客户端更新
```

| 角色 | 主表面 |
|------|--------|
| agent | 浮窗；无 Dashboard 管理权限 |
| coach | Dashboard + 工单文件导入 + 话术优化待办处理 + 内容导入确认 |
| owner | Dashboard / 发布 / 回滚 / 授权范围内分析导出 |

一期客户端边界为 **Windows Electron**；macOS 后续评估；iOS / Android 不进一期。

## 2. 范围

### 2.1 一期 Must

| ID | 能力 |
|----|------|
| M-Float | 粘贴/热键 → TopK 原文 → 点选 → **主 CTA 复制剪贴板**；自动填=实验 |
| M-Log | query + impression + adoption + dismiss + escalate；保留 `adoption_events` / `push_method` 机器兼容；重选以 `parent_query_id + attempt_kind` 归根 |
| M-AutoFacts | 自动事实仅脱敏问法、绑定 `release/script/version/hash` 的候选、成功复制、无命中、放弃、升级与重选；不推断修改 / 发送 / 正确 |
| M-Review | 修改、发送、适用性按离线三维样本分别复核；样本量、不可核验与证据等级分账 |
| M-TrainPrewire | schema + 空模板 + 纯合成 fixture；只允许检索 / 意图 / 重排用途；无真实训练、教师调用或模型发布 |
| M-Dash | 概览、工具 KPI、流水、话术优化待办、工单分析、内容发布、公告；**话术零写** |
| M-WorkOrder | 批准的 CSV/XLSX → 预检 / 映射 → 标准化 → 聚合 / 筛选 / 下钻 → 脱敏导出；`work_order_*` 独立域 |
| M-Iteration | 无命中 / 跳过 Top1 等生成 `iteration_task`；开始 / 关闭受控；不自动改库 |
| M-Content | **受信来源版本 → Import → Publish → Announce**（Excel/CSV 默认；飞书 API 适配预留）；每 release 恰好绑定售前/活动/售后/产品四域不可变 `use_class=canonical` 来源版本 |
| M-SourceGuard | canonical/current 只由 `content_current` + 当前 release 四域 binding 推导；未登记或 `reference` 来源拒绝；来源暂停永久只追加；文件行不得自报 `source_ref/source_version`；import/publish/rollback/search 全链 fail-closed |
| M-ContentIdentity | Answer 与 Question 分资产；Question 使用上游给定稳定随机 ID、独立 version/hash、semantic family、HMAC 来源指纹与删除血缘；禁止按导入行序生成 ID |
| M-ExplicitScope | `platform_scope` 必填非空且仅千牛/抖音；商品范围必须显式 `storewide/category/sku + refs`；`effective_from/review_due_at` 必填，禁止以 `NULL/[]` 放宽范围 |
| M-TaxonomyRisk | `intent_taxonomy_version + intent_id` 必填且可迁移；未知意图隔离；普通 Content Lead 单审，高风险/冲突 Content Lead + `ROLE-CS-MANAGER` 双审 |
| M-ContentQuality | 结构/安全/来源错误整批失败；质量问题行可隔离；clean 行按 `<=500` 全审、`501–5000` 抽 10%（100–300），问题率 `>2%` 扩 30%、`>5%` 阻断，高风险/冲突全审 |
| M-Placeholder | 仅 `{订单号}/{日期}`（`order_id/date`）；API 返回模板原字节，客户端内存确定性渲染；缺值禁止复制并二次确认；值/渲染正文零落库零日志 |
| M-OfflineLease | 客户端只读快照使用服务端短租约；ACK 只确认同步游标且不续租；离线租约到期立即停止本地检索，联网取得新租约后方可恢复 |
| M-Auth | 开发 / 演示可 Mock 且显著标注；试点和生产必须真实飞书 OAuth + 服务端 RBAC |
| M-NoRewrite | 引擎级：API Answer 模板字节=库；`policy.rewrite=OFF`；唯一允许变化是声明占位符在客户端内存中的确定性替换，不得 LLM 改写 |
| M-Human | 禁止自动代发 |
| M-SoR | **PostgreSQL 权威**；客户端缓存非真相源 |

### 2.2 后置

macOS 客户端、桌宠、完整 CMS 编辑器、向量线上主路、DeepSeek 一期非 Must、经营大盘、班牛实时 API、自动建单 / 填单 / 回写、真实训练、生成回复训练、一期完整数据集导出。真实飞书 OAuth **不是后置项**，而是试点前硬里程碑。

### 2.3 两类“工单”术语门

| UI 名称 | 代码 / 数据命名 | 来源 | 目的 | 禁止混用 |
|---------|-----------------|------|------|----------|
| **工单分析** | `work_order_*` | 班牛 / 业务系统批准的导出文件 | 业务质量与结构分析 | 不生成内部改库状态，不写回源系统 |
| **话术优化待办** | `iteration_task*` | 搜索 / 复制兼容事件信号 | 提醒话术师或工程改进 | 不承载业务工单原始明细 |

`ticket`、`iteration_ticket` 和单独“工单待办”不再作为当前契约术语。

### 2.4 内容重心

业务建设顺序仍是产品 + 活动优先，但来源治理不得缺域：每个可发布 release 必须同时绑定售前 `presale`、活动 `campaign`、售后 `aftersale`、产品 `product` 四个域各一个不可变 `use_class=canonical` 来源版本。未登记或 `reference` 来源不得发布/检索；没有“文件自己声明为 canonical”的路径，也没有可变 `current` 来源开关。

来源版本一旦出现只追加暂停记录，就永久不得再次 import / publish / rollback / search；恢复业务只能登记新来源版本，并通过一次原子发布生成新 release 与四域绑定。暂停不复用 `scripts.status` 或 `content_releases.status=superseded`。

## 3. 浮窗

| 项 | 冻结 |
|----|------|
| 卡片 | 标题 + 分类 + 全文；无分数 |
| 平台 / 商品范围 | 必须显式匹配 DEC-042；未知平台或商品上下文不得靠空 scope 放宽，只允许命中明确 `storewide` 商品范围 |
| 推送 | **复制到剪贴板**为主；有占位符时先在客户端内存补齐并二次确认，缺值禁复制；自动填实验；toast 禁“已发送” |
| 复制 | **仅 push 成功** 才写兼容值 `adopted`（clipboard/autofill）；不得解释为已发送 |
| 使用结果 | 不设强制自报；复制只记自动事实，修改 / 发送 / 适用性只按离线三维样本复核，不采最终正文 |
| 平台 | 人读 confirmed 映射 wire/DDL canonical=`platform`，Phase 1 必须经用户确认；直接手选/修正=`platform_source=manual`，接受热键瞬时 `detected_platform` 提示=`foreground_process`，提示本身非自动真源；禁止轮询 / 窗口标题 / 剪贴板历史；未来 `native_integration` 另批 |
| telemetry 降级 | 可进入显著标记的 `collection_disabled/stateless` 安全搜索并排除指标 / 语料；DLP、Auth、内容不就绪仍 fail-closed |
| hit | ≥1 可点选；不垫假卡 |
| 空态 | 找谁 + 飞书 / 复制联系 → escalate |
| 有效期 | **引擎永远过滤**；seed 须在窗内 |

## 4. Dashboard

| 模块 | 冻结 |
|------|------|
| 概览与工具指标 | 只读中心 SoR 事件；经营指标留在平台后台 |
| 检索 / 复制流水 | 根问题 / 操作双账；候选绑定 release/script/version/hash；脱敏问法按 capability 受权下钻；不展示最终发送正文 |
| 离线复核 | 坐席层 × 业务场景 × 自动事实结果三维抽样；修改 / 发送 / 适用性各自分母，不可核验分列 |
| 工单分析 | 手工导入批准文件；聚合 / 筛选 / 下钻 / 脱敏导出；不写回班牛 |
| 话术优化待办 | `iteration_task` 状态受控；与业务工单分表 / 分 API / 分权限 |
| 内容 | Dashboard 零写正文；权限内触发导入、Publish、Rollback；展示四域来源版本、稳定 Question 版本、显式 scope/taxonomy/risk/placeholder、审核与质量隔离、绑定完整性、永久暂停与拒绝审计 |
| 公告与同步 | 区分 published、announced、client ACK、offline lease；租约过期不再本地检索，不合并成一个“已同步” |

详细交互、状态、错误和验收见 [`29-Dashboard产品说明`](29-Dashboard产品说明.md)。

## 5. 指标与评测

| 工具侧（Dashboard） | 经营侧（平台） |
|--------------------|----------------|
| 根问题 / 操作数、复制率 `adopted/hit`（兼容字段）、无命中 / 放弃 / 升级 / 重选率、Top1 复制占比、P95；离线复核三项另账 | 响应 / 满意 / 转化 |

`hit` = `hit_status=hit`；`adopted` 只蕴含 push 成功。复制不能证明平台实际发送或回答正确。G1a 冻结预检集至少 **50 条且不可与 train、调参集、REAL-FWD 混用**：20 条正常正例、至少 12 条安全负例（6 类 × 2）、至少 18 条长尾 / 错别字 / 改写 / 上下文鲁棒性样本。REAL-FWD 只用于 G1b 与扩面。

人数统一为：验收最低 3 人；计划首批 4 人（2 新 + 2 老）；允许 3～5 人；业务扩面目标 50～100 人；架构容量仍为 50～150 人。

工单分析另按导入完整性、字段拒绝、聚合口径、越权、脱敏导出和审计验收，不与话术 Top3 指标混成一个总分。

## 6. 技术（摘要 · 详见 37）

| 项 | 冻结 |
|----|------|
| 拓扑 | **本机壳 + 中心 API + Postgres** |
| 语言 | **TS** 主；Python 二期清洗旁路；Rust 一期不上 |
| 检索实现 | 一期线上中文 bigram；本地开源 embedding 仅离线影子；接口稳定 |
| 本地 SQLite | **仅缓存 / Demo profile**，非跨用户 SoR |
| Demo profile | 可单机临时库 + 单窗 Tab + Mock；**不得**关闭有效期过滤 |
| 业务工单 | 仅白名单标准化字段入库；原始文件保留与出域另批；无外部写回 |
| CR-002/003 数据 | `0/14/30` 待 G0-11；语义资产晋级须二次 DLP、业务 + 数据安全双审与删除血缘；行为只产候选 |
| CR-004 来源治理 | 每 release 四域不可变 binding；current/canonical 由 current release 推导；暂停永久只追加；来源切换与发布原子；拒绝审计独立提交；33/OpenAPI 静态合同同批对齐，运行实现与证据待后续里程碑 |
| 训练 / 教师 | **一期仅训练合同、空模板与纯合成 fixture，不训练、不调用外部教师；二期须另行取得范围 / 数据 / 安全 / 费用授权后，才可只训练检索 / 意图 / 重排并按双周版本人工发布；三期客服 Agent / 生成回复另立项。** DeepSeek 可替换，GLM 无书面授权禁蒸馏；未来 teacher-run 不可变且受 cap |
| 权限扩展 | 继续使用 `agent / coach / owner`；审核、隐私、排障等是附加 capability，不替换现有角色 |

## 7. Demo 附页（业务确认）

Must 故事：粘贴 → Top3 → 复制 → 同 `query_id` 流水；禁改写抽查；脱敏 / 合成工单文件 → 预检 → 聚合 → 下钻 → 导出。
