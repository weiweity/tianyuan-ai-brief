## 1. 证据等级

| 证据 | 自动记录 | 可以证明 | 不可以证明 |
|------|----------|----------|------------|
| 脱敏搜索问法 | 是；DLP 通过时存脱敏正文，受抑制时只存状态 | 用户向本产品发起过一次搜索操作 | 外部平台完整客户原话或上下文 |
| 候选展示 | 是；每个候选绑定发布快照和内容哈希 | 当时系统展示了哪些已发布候选 | 用户阅读、理解或认可了候选 |
| 成功复制 | 是；剪贴板写入成功后记录 | 指定候选被成功复制 | 已粘贴、已发送、未修改或答对 |
| 无命中 | 是；搜索终态 | 本次操作没有合格候选 | 知识库一定缺内容或客服问题无解 |
| 放弃 | 是；`dismissed` 或客户端生命周期 `timeout` | 本次搜索操作未形成成功复制 | 放弃原因、是否转用其他话术 |
| 升级动作 | 是；辅助动作事件 | 用户点过批准的升级入口 | 问题已被接手或最终解决 |
| 人工抽样复核 | 否；应用外版本化 EVD | 样本在冻结口径下的修改、发送、正确性判断 | 未抽样总体的真实结果或因果收益 |

产品、Dashboard 和汇报中统一称“成功复制”或“复制率”。`adoption_events`、`outcome=adopted` 与 `push_method` 仅是既有机器兼容名，严禁在人读层解释为采纳、发送或正确。

## 3. 自动事实状态机

### 3.1 主流程

```text
用户主动输入问题
    → Auth / Notice / Policy / DLP / Content 检查
    → query_event(interaction_reason=original|reselection)
    → candidate_impressions(0..3，绑定 release/version/hash)
    → 仅形成一个搜索操作终态：
         adopted      = 剪贴板写入成功
         dismissed    = 用户明确关闭/放弃
         no_hit_exit  = 无命中后退出
         timeout      = 客户端生命周期超时
    → 可选 escalate_actions（辅助动作，不是搜索操作终态）
    → Dashboard 分别聚合 root question 与 search operation
    → Pilot 获批后，应用外按冻结方案抽样三维复核
```

### 3.2 Parent / reselection

`query_events` 增量冻结：

- `interaction_reason ∈ {original, reselection}`；
- `original` 必须 `parent_query_id IS NULL`；
- `reselection` 必须 `parent_query_id IS NOT NULL`；
- parent 必须存在、属于同一服务端用户，且已有一个合法搜索操作终态；
- 禁止自指、环、跨用户父链及写入后改父；
- 一次重新选问法创建新的 query/search operation，不能覆盖父 query；
- root question 沿 parent 链解析；断链或循环必须 fail-closed，不得静默重算。

这套谱系用于区分“一个真实问题反复搜索”与“多个独立问题”，不是聊天会话树，也不保存外部消息。

### 3.3 候选来源与哈希

每条 `candidate_impressions` 必须保存并校验：

- `release_id`；
- `script_id`；
- `script_version`；
- `content_hash`；
- `rank` 与服务端时间。

四个内容来源字段必须以复合外键指向不可变 `release_items(release_id, script_id, script_version, content_hash)`。不能只保存 `script_id` 后读取当前正文，也不能让客户端提交任意版本/哈希。复制事件必须精确引用当次展示候选。

### 3.4 成功复制、放弃与客户端超时

- 机器兼容表仍为 `adoption_events`；它承载的是**搜索操作终态**，不是人读“采纳”；
- `adopted` 只在剪贴板写入成功后提交，且 `push_method∈{clipboard,autofill}`；一期 UI 只产生 `clipboard`；
- `dismissed / no_hit_exit / timeout` 的 `chosen_rank` 与 `chosen_script_id` 必须为空；
- 同一 query 只有一个搜索操作终态；重复同体幂等，异体冲突稳定拒绝；
- `CLIENT_ACTION_TIMEOUT_MS` 是部署/客户端生命周期策略，不进入事件表。客户端在浮窗关闭、切后台或 idle 达阈值后上报唯一 `timeout`；服务端时间为权威时间；
- 客户端崩溃、离线或事件链残缺不得事后猜测补终态，也不得把未知自动算作成功复制。

### 3.5 升级是辅助动作

- `POST /v1/events/escalate` 必须携带 `Idempotency-Key`；
- `escalate_actions` 以 `(query_id, action)` 唯一；同一 query 可以产生不同批准 action，但同 action 重试不能重复计数；
- 服务端从可信身份推导 user，验证 query 归属；
- 升级不覆盖、替换或自动生成搜索操作终态；
- `escalate_action_count` 与 `root_escalated_count` 分账，不能把辅助点击次数冒充已解决问题数。

### 3.6 不变量

- `INV-AUTO-01`：在线没有发送、修改或正确性字段、表、写入路由或组合结果枚举；
- `INV-AUTO-02`：复制成功必须引用同 query 的真实候选 release/version/hash；
- `INV-AUTO-03`：一个 query 最多一个搜索操作终态，升级动作不抢占终态；
- `INV-AUTO-04`：reselection 追加新 query，不覆盖父记录，且父链无环、同 user；
- `INV-AUTO-05`：客户端 timeout 使用批准配置并只上报一个终态；
- `INV-AUTO-06`：自动代发调用次数恒为 0；
- `INV-AUTO-07`：`work_order_*`、自动事实和 `iteration_task*` 不混表、不共用原始明细。

## 4. 根问题 / 搜索操作双账

Dashboard 同时报告两种分母，名称与公式不得混用：

| 指标 | 分母/口径 |
|------|-----------|
| `root_question_count` | parent 链去重后的根问题数 |
| `search_operation_count` | 全部合法 query/search operations |
| `reselection_count` | `interaction_reason=reselection` 的操作数 |
| `root_adopted_count` | 至少一个操作成功复制的根问题数 |
| `root_adoption_rate` | `root_adopted_count / root_question_count`；兼容字段名，人读为根问题复制率 |
| `operation_adopted_count` | `outcome=adopted` 的搜索操作数 |
| `operation_adoption_rate` | `operation_adopted_count / search_operation_count`；人读为操作复制率 |
| `escalate_action_count` | 幂等去重后的升级辅助动作数 |
| `root_escalated_count` | 至少发生一个升级动作的根问题数 |

空分母返回 0；延迟在空窗返回 `null`。必须同时返回原始计数与比率。根问题成功复制后又重新搜索的情况，root 只计一次成功，operation 按实际操作计数。

`GET /v1/metrics/stream` 可以按授权范围查看脱敏问法、parent/reselection、候选来源、搜索操作终态及升级辅助动作；不得返回最终发送文本、人工复核结论或训练集成员身份。

## 7. 降级、失败与隐私

### 7.1 Telemetry 故障

仅事件链故障而 Auth、DLP、Policy、内容快照仍可信时，可以进入明确标记的 `collection_disabled/stateless` 安全搜索：

1. 不写 query、impression、搜索操作终态或升级动作；
2. 不进入 Dashboard、候选语料、G1b 或训练预埋；
3. 不用日志、崩溃记录或事后推断回填；
4. DLP/Auth/Content/Notice 失败仍必须 fail-closed。

### 7.2 数据最小化

- raw 问法只在受控内存中完成 DLP，不进入日志、异常、缓存或本地持久化；
- SoR 只保存获批脱敏问法，或 `suppressed` 状态；
- 候选只保存发布引用与哈希，不复制未批准正文；
- 不保存聊天、最终发送文本、窗口标题、全局剪贴板历史；
- 14 天脱敏正文、30 天个人结构事件仍只是 G0-11 建议值，不是已授权保留期。

### 7.3 应用外三维抽样

只有真实数据与 Pilot 均获批后，才可按预先冻结的方法生成离线 EVD。三个维度独立，不组合成在线终态：

| 维度 | 离线值示例 | 必报 |
|------|------------|------|
| 修改程度 | 未改 / 轻微修改 / 实质修改 / 完全重写 / 不可判断 | 各值样本数、已复核分母、不可判断数 |
| 是否发送 | 已发送 / 未发送 / 不可判断 | 各值样本数、已复核分母、不可判断数 |
| 正确性 | 正确 / 错误 / 信息不足无法裁决 | 各值样本数、已复核分母、裁决规则版本 |

抽样规则、时间窗、分层、样本量、审核人和证据版本必须在看结果前冻结。复制、放弃、无命中或升级只是抽样信号，不能直接成为三维标签。当前 OpenAPI 不存在人工复核队列或结论写入 API。

## 9. CR-003 训练预埋边界（引用 49 / 50）

CR-002 只提供受控候选引用；训练数据链、教师运行合同与测试由后续 **49 / 50** 承担。当前只冻结以下接口边界：

1. **0 / 14 / 30：** raw 问法持久化为 0；脱敏问法正文建议上限 14 天；个人结构事件建议上限 30 天。14/30 均待 G0-11，不能写成已授权。训练 artifact 没有独立批准时同样不得保留真实正文；
2. **semantic promotion：** 运行事件只能进入候选引用；必须经人工语义归并、去重、用途审核和版本化 promotion 才能进入批准训练集；
3. **教师许可：** DeepSeek 只有在具体模型条款、采购、数据出域和蒸馏用途批准 ID 齐全时才能作为 teacher；GLM 当前明确禁止用于蒸馏；
4. **三账分离：** `real / policy / synthetic` 分别记录来源、授权、样本数、成本和失败，不合并分母，不把合成样本冒充真实问题；
5. **严格 JSON：** teacher 输入输出必须 `additionalProperties:false`、长度/枚举受控；客户问法、政策文本和模型输出一律按不可信数据处理，拒绝 prompt 注入、越权指令与非 JSON 尾随文本；
6. **Embedding 离线影子：** 只在获批离线集合上运行，不参与一期在线召回、排序或通过指标；
7. **本地 student：** student 默认本地受控运行，禁止真实数据静默出域；模型与许可证另行签发；
8. **泄漏为 0：** train/G1a/G1b 在 sample id、精确指纹、semantic cluster、lineage group 和模板祖先上交集均为 0；
9. **teacher run：** 每次记录 provider/model/version、许可批准 ID、prompt hash、输入 dataset hash、输出 hash、参数、token、实际成本与预算 cap；越 cap fail-closed；
10. **无自动路径：** 一期没有 runtime→train 自动任务、公开训练 API、自动发布或完整数据集导出。

49/50 的设计不得扩大 CR-002 真实数据授权，也不得把 notice acceptance 偷换成训练二次用途授权。

## 10. 门禁与停止开关

| 门 | 当前结论 |
|----|----------|
| 静态架构 | **PASS-WITH-CONDITIONS** |
| G0 | **待签** |
| Ddev | **未授权** |
| 真实数据 | **NO-GO** |
| Pilot | **NO-GO** |
| 自动代发 | 永久禁止 |

出现以下任一情况立即关闭真实采集，必要时只保留安全搜索：

- 未脱敏文本进入日志、事件、缓存、索引、EVD 或导出；
- parent 跨用户、成环、改父，或候选 release/hash 无法校验；
- 相同搜索操作/升级动作被重复计数；
- 系统推断或在线收集修改、发送、正确性；
- 根问题与搜索操作分母混算；
- train/G1a/G1b 泄漏不为 0；
- 未获许可的 teacher、GLM 蒸馏、预算越限、自动训练、自动改库或完整数据集导出被启用；
- 自动代发或外部平台写回被启用。

## 11. 验收摘要

CR-002 只有同时满足以下事实，才可称“静态设计已对齐”：

- 是现有 search/events/Dashboard 增量，不替换 SSOT；
- 自动事实仅限脱敏问法、候选、成功复制、无命中、放弃和升级；
- 在线合同没有使用结果回填、组合结果枚举或正确性写入；
- 修改、发送、正确性按 Pilot 离线抽样三维分账；
- parent/reselection 无环同 user，候选绑定不可变 release/version/hash；
- 升级辅助动作幂等，客户端 timeout 不造第二终态；
- 根问题与搜索操作双账同时返回计数和比率；
- stateless 排除指标、语料和 G1b；
- CR-003 仅预埋 49/50 边界，未扩大真实数据、训练、出域或付费授权；
- 当前仍是 **STATIC PASS-WITH-CONDITIONS；G0/Ddev/真实数据/Pilot 均未放行**。
