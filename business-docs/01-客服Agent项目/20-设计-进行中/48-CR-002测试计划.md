## 0. 测试目标

本计划验证 D1：系统自动记录脱敏搜索问法、候选、成功复制、无命中、放弃和升级；是否修改、是否发送、是否正确只在获批 Pilot 中按冻结抽样方案离线复核，三个维度单独统计。

必须防止以下伪事实重新进入产品：

- 复制被写成已发送、已采纳或正确；
- 在线回填或系统推断外部平台行为；
- 一个根问题的多次重新选择被算成多个独立真实问题；
- 候选只按 `script_id` 回读当前正文，丢失发布版本；
- 升级辅助点击抢占搜索操作终态或被重复计数；
- 客户端超时生成多个终态；
- 用文件行序/正文 hash 伪造稳定 Question 身份，或改变 Question/治理快照后沿用旧版本/hash；
- 空 scope、旧 `sku_hint` 或未成对 product context 被当成全平台/全商品授权；
- 未知 taxonomy、缺审核、quarantine/未决冲突内容进入 TopK；
- 把 placeholder 值或客户端渲染正文写入事件、日志或训练候选；
- 运行事件自动进入训练集、G1a 或 G1b；
- 静态设计通过被冒充 G0、Ddev、真实数据或 Pilot 通过。

## 2. 测试数据

### 2.1 合成固定夹具

- `query_original_hit`：original，Top3，复制 Top1；
- `query_reselection`：父 query 已有合法终态，换问法后复制 Top2；
- `query_no_hit`：无候选后退出；
- `query_dismissed`：有候选但明确关闭；
- `query_timeout`：有候选，客户端生命周期达到 `CLIENT_ACTION_TIMEOUT_MS`；
- `query_escalated`：无命中后点一次批准升级动作；
- `query_suppressed`：DLP 允许检索但禁止保存脱敏正文；
- `query_stateless`：事件链不可用但安全搜索仍可用；
- `query_parent_cross_user / self / cycle`：父链攻击夹具；
- `candidate_wrong_release / version / hash`：候选来源篡改夹具；
- `question_identity_reorder / mutate / promotion_role / reversible_origin`：导入重排、Question 改版、晋级角色变更与可逆来源指纹负例；
- `scope_platform_empty / product_context_pair / storewide_only`：显式平台与 `product_context_type=category|sku + product_context_ref` 成对夹具；
- `taxonomy_unknown / risk_high / content_conflict / quarantined`：taxonomy、high/冲突双审与隔离夹具；
- `placeholder_order / date / missing / unknown`：`{订单号}`/`{日期}` 内存渲染、缺值与未知 token 夹具；
- `quality_clean_500 / clean_501 / defect_2pct / defect_5pct / same_count_row_swap`：全审、抽样、扩样、阻断边界与同计数换行攻击夹具；
- `governance_snapshot_ascii_permutation / locale / mutation`：固定 ASCII 治理键集、数据库 `C` 排序、locale 差异与任一治理字段变更夹具；
- `semantic_asset_active / retired / tombstoned / source_query_delete`：语义来源资产退役、墓碑和来源 query 删除顺序夹具；
- `snapshot_full_release / effective_from / effective_to / public_field_injection`：完整不可变快照、客户端半开区间过滤与公开字段泄漏夹具；
- `batch_content_contract_invalid / governance_hash_mismatch`：两类 fatal error code 与批次终态夹具；
- `strict_json_injection_set`：尾随文本、未知字段、角色指令、Unicode 混淆和超长嵌套。

所有夹具使用虚构标识，不含真实客户、坐席、订单、工单或聊天内容。

### 2.2 数据源标签

测试和 CR-003 预埋统一使用 `synthetic / policy / real` 三类来源。`real` 在当前阶段必须为 0；`approved_redacted` 只表示现有审批范围内的脱敏样例，不自动获得训练或出域许可。

| `CG-014` | T1/T2 | high/冲突与普通 clean 混合批 | high/冲突 100% 审且不进普通抽样分母；总体由稳定、安全的行身份元组排序并计算 `population_manifest_hash`；plan 先冻结规则/cutoff/分母/seed/hash，审核池后写 evidence；缺失、blocked 或总体身份漂移时 finalizer 拒绝 |
| `CG-015` | T1 | worker/审核池权限互换 | 普通 worker 调 review decision/evidence 或直写受限表失败；审核池不得 claim/finalize import；PUBLIC 全部失败 |
| `CG-016` | T1/T2 | app_runtime 直读/自拼 scope | 直读 backing view/底表 permission denied；仅受控 search 函数可返回候选，空平台、scope 缺对或绕过质量/审核条件稳定拒绝 |
| `CG-017` | T1/T2 | 同计数换行攻击 | 在 clean 总数、抽样数与缺陷数均不变时替换一条行身份；`population_manifest_hash` 必须变化，旧 evidence 不可复用，finalizer 重算后拒绝 |
| `CG-018` | T1/T2 | 语义来源资产退役/墓碑与 query 删除 | active 资产可追溯；退役或墓碑后禁止新推荐/晋级但保留最小删除血缘；直接先删仍被引用的 `from_log` query 必须受 FK/流程阻断，只有完成资产退役/墓碑和血缘释放后才能按序删除 |
| `CG-019` | T2/T3 | 完整 snapshot 与生效边界 | 同一 release 的 snapshot 分页返回完整不可变集合，不由服务端按当前时间裁剪；客户端使用 `effective_from <= now < effective_to` 本地过滤，`now == effective_to` 明确排除，翻页/重试结果稳定 |
| `CG-020` | T0/T2 | 公开对象闭包与 mapper | OpenAPI 所有公开对象均 `additionalProperties:false`；`PublicSnapshotQuestion` 只允许最小白名单；handler 使用显式 mapper，禁止数据库 row spread；审核 EVD、HMAC、内部 locator/query/source 血缘字段注入响应时合同测试失败 |
| `CG-021` | T1/T2 | 拒绝审计原因分区 | 来源许可、来源身份或租约拒绝只写来源拒绝审计；内容合同、质量、governance hash 失败只写标准批次/安全审计，不得伪装为 source denial；两路均可按批次关联且不泄露敏感正文 |
