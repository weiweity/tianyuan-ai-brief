## 0. 测试目标

验证一期确实只预埋一条可审计训练链，且任何运行行为都不能绕过二次 DLP、业务 + 数据安全双审、用途锁定、评测隔离、删除血缘、许可与预算门进入训练或发布。同时验证 DEC-042 输入治理：只有稳定 Question 身份/版本/hash、显式 scope、已批 taxonomy、完成风险审核、非 quarantine 且绑定固定 ASCII 键集 + `COLLATE "C"` 规范治理快照的**模板候选**才可进入后续离线晋级；placeholder 值和客户端渲染正文永不进训练链。

必须阻断：

- 将复制、重选或发送猜测直接标成正确标签；
- 将 14/30 天运行保留误写成长期训练授权；
- 用向量、teacher output、checkpoint 或备份绕过删除；
- Question 与当前 Answer 松绑定，导致训练 / 评测引用错误版本；
- 以导入行序/正文 hash 充当 Question 身份，或改问法/映射却不升版本/hash；
- 改变 `promoted_by_role` 却复用旧 Question hash，或把任意 Unicode 对象冒充通用 JCS；
- 空平台/商品 scope、未知 taxonomy、未完成 high/冲突双审或 quarantine 内容进入语义候选；
- 占位符值、客户端渲染正文或二次确认内容进入 artifact/embedding/teacher/student；
- 只对 Answer 正文求 content hash，或越过质量 quarantine/抽样阈值把未审核 clean 行当成可训练资产；
- 只比较总体计数而不绑定 `population_manifest_hash`，使同计数换行复用旧质量证据；
- 已退役/墓碑语义资产重新进入候选、embedding、teacher 或训练，或先删除仍被引用的来源 query；
- `train / G1a / G1b` 的同义改写、同模板或同来源泄漏；
- 未授权 DeepSeek / GLM、提示注入、未知字段或越限费用；
- 自动训练、在线连续学习或自动发布；
- 用纯合成绿灯冒充真实数据、G0、Ddev 或 Pilot 通过。

| `CQ-009` | T1/T2 | 普通 worker 自报审核/质量通过 | normalized row 含 review mode、审核主体/角色/EVD/结论或 `quality_gate_passed` 时整批拒绝；worker 只能 freeze quality plan，不能 record review/evidence |
| `CQ-010` | T1/T2 | 质量 plan/evidence 漂移或同计数换行 | `content_quality_review_plans/evidence` 必须经受限函数分账建立；总体由稳定、安全的行身份元组排序后计算 `population_manifest_hash`，evidence 绑定同一 plan/batch/hash，finalizer 重算；即使总体数、样本数和缺陷数不变，只替换一行也必须拒绝旧 evidence，候选不得进入离线链 |
| `CQ-011` | T1/T2 | 两类 fatal error code | 内容合同破坏落 `CONTENT_CONTRACT_INVALID`，治理 hash 不一致落 `GOVERNANCE_HASH_MISMATCH`；两者都原子终止整批且无部分候选；来源拒绝审计只接来源/租约原因，内容、质量、hash 错误进入标准批次/安全审计 |
| `CQ-012` | T1/T2 | retired/tombstoned 资产重入 | 已退役或墓碑的 semantic source asset 即使正文、hash、审批或 release 仍可查，也不得进入 artifact、embedding、teacher、student 或任何新 dataset version；恢复使用必须新建受审资产版本，不能原地复活 |
| `CQ-013` | T0/T1 | 规范 hash 负例闭包 | 固定 ASCII 键重排与数据库 locale 变化保持确定结果；增加未知 Unicode 键、改变 `promoted_by_role` 或任一治理字段均拒绝旧 hash；静态文档不得把该受限算法写成完整 RFC 8785 JCS 实现 |

**分层退出：** DEV-M0 以 schema/contract/hash/ACL 负例证明机器边界；DEV-M1 以搜索不返回不合格治理项证明候选入口；DEV-M2 以 import/publish/quarantine/抽样阈值证明内容门；DEV-M3 以客户端内存渲染+二次确认+零持久 E2E 证明 placeholder 边界。当前均尚无运行 EVD。
