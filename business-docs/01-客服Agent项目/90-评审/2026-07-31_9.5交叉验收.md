## 3. 本轮关闭的高风险反例

1. 公开模板不再直链被忽略的原始纪要，只登记受控 `EVD-*` ID。
2. 人员、代理人、审核人与证据字段改为完整格式白名单，中文姓名或原始 URL 夹带会失败关闭。
3. `CUSTOMER_PROJECT_MODE` / `CUSTOMER_PROJECT_ROOT` 必须成对；未知模式、仓内路径、相对路径和末级符号链接均被拒绝。
4. 私有 QA 不再把含真实状态的截图 / JSON 写回公开仓工作树。
5. 资源基线已纳入台账、PRD 契约、Hub 状态条与漂移反例，不再静默过期。
6. G0 签发记录必须与章程、台账、Scope、排期的当前版本精确一致。
7. 历史 Web 移动端 t7 从重叠网格改为单一纵向滚动流，并新增可视后代内容相交断言。
8. 汇报 Web 已明确为历史快照；现行 PRD / 执行中心入口和 Pages 边界已验证，R-09 关闭。
