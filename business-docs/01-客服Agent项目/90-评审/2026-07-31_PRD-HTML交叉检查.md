## 2. 内容交叉检查

本轮已修正以下高风险表达：

1. 将 `14 / 14 + 15 / 15` 明确为**通过门槛**，并显示当前真实状态 `0 / 14`、`0 / 15`、G0 未签发；
2. 将验收责任改为“客服业务 Owner（待具名）”，不虚构具体负责人；
3. Scope 补回平台 / 场景、受控问答、仅使用已发布且有效内容；
4. 明确错误直答、自动代发、越权泄露任一大于 0 即失败；
5. 区分 A、B、C 三类费用证据，不把正数 cap 错写成 B 路径要求；
6. 跨职能日期补充完整资源成立条件，单人全栈保留为保守基线；
7. 供应链只保留“能力不进入本项目”的边界，不在 PRD 复制其组合状态；
8. 七个业务真源链接均回到当前客服 Agent 项目目录，并收纳到维护人员折叠区。

状态、日期、门禁、指标与两套资源情景均已和当前项目真源核对。
