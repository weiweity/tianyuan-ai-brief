## 4. 非阻断 P2

- PRD 在 375 px 连续快速点击导航时，`aria-current` 可能短暂落后一个章节；URL 和目标位置正确；
- PRD 的 `#meeting-prep` 指向折叠内容，单轮深链探测未自动展开；
- PRD 的资源情景容器、执行中心的角色筛选容器仍有 generic `div + aria-label` 语义复核项；
- 执行中心维护抽屉内七个原始链接高度约 26 px；该区默认折叠且只供维护人员使用；
- 执行中心 390 / 375 首屏优先展示结论和门禁，第一行动位于下一屏；
- 执行中心 `#G0-04` 深链存在，但单轮对抗探测未稳定滚入可见区；
- 独立脚本观察到一次打印后默认折叠状态未完整恢复；标准双轮打印状态测试均通过；
- 非法 URL fragment 仍可触发 `querySelector` 页面错误，正常导航只生成合法 ID；
- Pretext 默认路径绑定当前机器，跨机器 CI 需设置 `PRETEXT_VENDOR` 或改为仓库相对 Vendor。

以上均为 P2，无数据错误、阻断交互、外部请求、安全漏洞或 P0 / P1。

```text

        ↓
内容解析与 14 + 15 门禁一致性校验
        ↓
SHA-256 Release + 七份真源逐文件哈希
        ↓
只读 HTML
        ↓
--check 字节级新鲜度门禁
```

验证结果：

- 人工篡改临时生成物后，`--check` 正确拒绝过期页面；
