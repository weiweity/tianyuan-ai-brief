## 1. 架构交叉验证

### 1.1 大厂 / 企业架构视角

当前冻结候选已经具备清晰 SoR、九端口、owner-only 发布、幂等与 fencing、batch→outbox 锁序、失败矩阵、SLI 和启动拒绝矩阵。最后一轮复核又补了六处实现者容易猜错的边界：

## 3. 架构补洞记录（历史输入，现已吸收）

> **效力：** 本节记录 2026-08-06 当时用于补洞的检索、安全、SLI、故障与恢复输入。有效内容已吸收到 37 / 39 / 41 / 47 / 49 及机器合同；从 2026-08-08 起，本节与全文都只作历史评审证据。若与现行规范冲突，以现行规范为准，不得从本节选择旧实现。

### 3.1 中文检索（A1）— 一期冻结

| 项 | 冻结 |
|----|------|
| 主路径 | PostgreSQL **Unicode 字符 bigram（2-gram）**。应用层按 Unicode code point 生成重叠 2-gram token，写入 `release_items` 的检索文档/`tsvector`；字段固定为 **questions(A) + title(B) + answer(C)**。`pg_trgm` 是 **3-gram**，只可加速相似度/ILIKE 回退，**不得冒充 bigram 主路径**。 |
| 规范化 | `normalize(q)`：Unicode **NFKC** → 英文小写 → 常见全角标点半角化 → 连续空白折叠为单空格 → trim；实现设计必须给固定输入/输出向量。 |
| 短查询 | 0 字符 → `VALIDATION`；1 个 Unicode code point 跳过 bigram，走 escaped exact/ILIKE；≥2 才生成重叠 bigram。 |
| 召回与回退 | 先在固定 `release_id` 上做 platform/sku/effective 强制交集，再合并 exact + bigram；无候选或分词失败 → **escaped ILIKE** 回退；始终只读 `v_scripts_recommendable`/等价固定 release snapshot。 |
| 排序 | exact boost + questions/title/answer 权重 + 稳定 `score desc, script_id asc`；可选 LLM ranker（超时 ≤400ms → INV-FB）只改顺序不得改 Answer。 |
| 评测 | 上线前 **≥50 条中文 query 金标**：20 正例 + ≥12 安全负例（六类 × 2）+ ≥18 鲁棒性；与开发 / 调参集不重叠；正例 Top3 分母固定 20，安全负例必须全过。hit@3 门槛产品另定，**架构要求：冻结集合可跑** |
| 禁止 | 依赖「仅英文 unicode61 默认分词」作为生产唯一策略 |
| 后置 | 向量检索 = Assess；不改 search 端口合同 |

> 技术校正依据：PostgreSQL 官方将 `pg_trgm` 定义为连续 **3 字符** trigram，并说明无可提取 trigram 的模式会退化为全索引扫描；因此它可服务回退/相似度，但不能与本项目冻结的 2-gram 主路径视为同义。见 [PostgreSQL `pg_trgm` 官方文档](https://www.postgresql.org/docs/17/pgtrgm.html)。

### 3.2 威胁模型 STRIDE 摘要（A2）

| 威胁 | 场景 | 缓解（设计） |
|------|------|--------------|
| **S**poofing 仿冒 | mock 身份进生产 | 生产 `AUTH_MODE≠mock` 拒启；真飞书 OAuth |
| **T**ampering 篡改 | 旁路改 published 正文 | DEFINER publish、不可变触发器、无 scripts 旁路视图 |
| **R**epudiation 抵赖 | 无审计 | change_audits + query/搜索操作终态事件（机器表 `adoption_events`） |
| **I**nfo disclosure | 日志含手机号 | redaction 落库前；最小权限 GRANT |
| **D**oS | 刷 search | 用户/全局 rate_limit；生产 `RATE_LIMIT_FAIL_CLOSED=true` |
| **E**oP 提权 | 坐席调 publish | RBAC：一期仅 owner 发布/回滚；API 鉴权 + DB 函数 ACL |

**信任边界：**\
Electron 渲染进程 **不信任**；preload 白名单 IPC；API **不信任**客户端角色声明（以 token 为准）；LLM **不信任**（不得写 Answer）。

| 外部结果 | 是否修改、是否发送、是否正确只在获批 Pilot 中应用外抽样，三维分别报告样本数、分母与未知项 |
| parent | `original` 必须无 parent；`reselection` 必须有同 user、已有终态的 parent；禁止自指、环、改父 |
| 候选谱系 | impression 强制 `release_id/script_id/script_version/content_hash` 并引用不可变 release snapshot |
| 终态 | 机器兼容枚举 `adopted/dismissed/no_hit_exit/timeout`；人读 `adopted` 只称成功复制 |
| timeout | `CLIENT_ACTION_TIMEOUT_MS` 是客户端生命周期策略，不进事件表；关闭/切后台/idle 只形成唯一 terminal |
| 升级 | `/v1/events/escalate` 必须 `Idempotency-Key`；`(query_id,action)` 唯一；辅助动作不替换终态 |
| 双账 | root question 与 search operation 同时返回原始计数和复制/升级指标，禁止混分母 |

### 3.7 CR-003 49/50 训练预埋（A7）

- raw/脱敏正文/个人结构事件按 `0 / 14 / 30` 设计；14/30 仍待 G0-11；
- runtime 事件只能进入候选引用，必须经 semantic promotion 才能进入获批离线数据集；
- DeepSeek teacher 必须有具体许可、采购、出域、蒸馏用途批准和预算；GLM 蒸馏禁止；
- real/policy/synthetic 三账分离；严格 JSON schema 抗 prompt 注入；
- Embedding 只做离线影子，本地 student 不允许真实数据静默出域；
- train/G1a/G1b 在 sample、指纹、semantic cluster、lineage 和模板祖先上泄漏均为 0；
- 每次 teacher run 冻结 provider/model/version、许可 ID、prompt/input/output hash、token、实际成本和预算 cap，越 cap fail-closed；
- 一期不存在 runtime→train 自动链、public 训练 API、自动发布或完整数据集导出。

上述增量只提高实现者可执行性，不改变本报告的历史评分，也不解除当前 G0/Ddev/真实数据/Pilot NO-GO。
