## 一期主流程

1. 坐席输入客户问题和必要的平台 / 商品 / 活动上下文；
2. 系统返回候选话术，同时显示来源、版本、适用范围和有效期；
3. 信息不足时先让坐席补充，不猜测；
4. 内容冲突、过期、越权或无依据时，明确升级到人工流程；
5. 坐席选择采用、修改、拒绝或转人工，再自行发送；
6. 系统记录查询、候选、编辑差异和最终结果，用于后续评测和语料建设。

## 必须设计的状态

| 状态 | 用户要看到什么 | 禁止 |
|------|------------------|------|
| 首次使用 / 空状态 | 能查什么、要填哪些上下文 | 用“什么都能问”误导坐席 |
| 查询中 | 明确进度和可取消行为 | 无限等待 |
| 有可用候选 | 话术 + 证据 + 适用范围 | 只显示一句无来源答案 |
| 需要澄清 | 缺哪个关键条件 | 系统自行补齐 |
| 冲突 / 过期 / 无依据 | 原因、升级方式、可回到原流程 | 错误直答 |
| 无权限 | 缺失权限与申请路径 | 泄露不可见内容 |
| 系统异常 | 保留输入、退回原流程 | 伪造成功结果 |
