# 客服 Agent 一期 · 数据与知识库设计

> **状态：** **ARCHIVED · SUPERSEDED**（初始草案，不得按现行执行）\
> **目标：** 把分散话术变成可查询、可更新、可下架、可追溯的受控内容\
> **详细字段与迭代信号：** 以现行 [`26-话术库与自动事实数据模型.md`](../../20-设计-进行中/26-话术库与自动事实数据模型.md) 为准\

## 一期最小数据对象

| 对象 | 必填字段 |
|------|------------|
| 话术条目 | 见 26：`script_id`、四类 category、answer 正文、状态、版本、有效期、维护角色 |
| 问法 Question | 见 26：挂 script、question 文本、来源 manual/from_log |
| 适用范围 | 平台、商品 / SKU、活动、渠道 |
| 时间范围 | 生效 / 失效 / 发布 / 下架 |
| 来源与版本 | 版本、content_hash、替代关系 |
| 采纳日志 | 见 26：query / impression / adoption |
| 迭代工单 | 见 26：无命中、跳过 Top1 等信号 → 提醒话术师 |

## 内容生命周期

```text
原始来源
  → 清洗与拆分
  → 适用范围标注
  → 内容复核
  → 发布版本快照
  → 检索索引
  → 使用与反馈
  → 修订 / 下架 / 回滚
```

任何时候只能有明确的已发布版本进入坐席查询。过期、冲突未裁决、超出适用范围或无权限的内容不得生成可直接采用的答案。

## 为二期语料库蒸馏预留

一期只记录可控、可脱敏的学习信号（详见 26）：

- 脱敏问法 / hash 聚类；
- Top3 候选与选用位次；
- 无命中与跳过 Top1 等迭代信号；
- 话术版本与最终选用 script_id。

二期再蒸馏回复库；一期日志 **不自动** 等于可训练数据。一期 **不因日志自动改 Answer**。
