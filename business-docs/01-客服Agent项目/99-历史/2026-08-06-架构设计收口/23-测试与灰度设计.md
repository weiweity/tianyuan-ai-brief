# 客服 Agent 一期 · 测试与灰度设计

> **状态：** **ARCHIVED · SUPERSEDED**（初始草案，不得按现行执行）
> **一期范围：** 3–5 名内部坐席灰度，默认人工确认后发送

## 验证顺序

1. **离线基线：** 关键词 / 规则方案与候选检索方案使用同一内容快照和冻结问题集；
2. **影子回放：** 不接触真实客户，业务盲审命中、引用、适用范围、过期 / 冲突和拒答 / 升级；
3. **冒烟测试：** 权限、主流程、异常流程、灰度开关、监控和回退可用；
4. **内部灰度：** 一期优先 2 名新手 + 2 名老手，覆盖不足时在 3–5 人内调整；
5. **评审结论：** 扩大、限时整改后重测或停止。

## 一期对比方法

一期样本小，不宣称统计显著性：

- 新手两人与自己使用前的匹配任务做环比；
- 老手两人与自己使用前的匹配任务做环比；
- 新手和老手分层报告，不直接用两组原始水平互相比较；
- 同时报告原始计数、分母、任务分层和活动期影响；
- 正式的同期分层 A/B 或准实验放到二期，避免中国电商大促、班次、平台、意图和新老手结构变化造成假结论。

## 指标组

| 类型 | 示例 |
|------|------|
| 效率 | 获得可确认安全答案的时长、查表 / 询问升级次数 |
| 质量 | 引用 / 版本 / 适用范围正确率、错误直答、大幅修改、拒绝 / 升级 |
| 使用 | 匹配任务数、去重使用坐席数、采用 / 修改 / 拒绝 |
| 稳定 | 成功率、延迟、错误、原流程回退成功率 |
| 费用 | 单个去重匹配任务成本、日 / 周总成本、cap 使用率 |

## 立即停止

- 自动代发或越过坐席确认；
- 错 SKU、错平台、过期活动或越权承诺被直接回答；
- 泄露敏感信息或越权访问；
- 权威来源冲突未裁决却给出确定答案；
- 系统不稳定影响客服正常接待，且无法快速退回原流程；
- 在冻结周期和匹配任务中没有看到提效方向，或错误 / 投诉风险上升。
