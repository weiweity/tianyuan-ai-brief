## 0. 10 分定义（可勾选）

### 0.1 产品诚实（Product Honesty）

- [ ] **主 CTA 唯一叙事：** 包甲/一期浮窗主按钮文案 = **「复制到剪贴板」**；自动填 = 实验项/次级，失败不得冒充成功。
- [ ] **采纳不注水：** `outcome=adopted` **仅当** `push_method ∈ {clipboard, autofill}`（推送成功）；点选后推送失败 → `push_method=failed`，**不进采纳分子**。
- [ ] **Demo ≠ 成品浮窗：** 08-12 明示「单窗 Tab 壳」；产品终态仍是 Electron 浮窗 + Dashboard 双表面。
- [ ] **Seed ≠ 飞书同步：** 包甲只用 `pnpm seed`；飞书改库 + 手动同步是规格/一期，**不在演示里装成已接通**。
- [ ] **Dashboard 权限表述准确：** 「话术只读 + 待办可写关单」；禁止写「全站只读」又关单写库。
- [ ] **指标分栏硬边界：** 工具侧只算 adopted/hit 等；经营三指标永不进 App 主 KPI。
- [ ] **PRD 与契约同词：** 25 不再写 DeepSeek/向量/工单分析为一期 Must。

### 0.2 架构（Architecture）

- [ ] **路线 A 冻结：** 全自研；无 Dify/RAGFlow 主中台。
- [ ] **services 无 Electron import；** main 只做 IPC + dialog + 剪贴板/自动填适配。
- [ ] **DB 策略：** 包甲默认 **sql.js**；better-sqlite3 仅 Day0 门禁绿后可选加速，失败不挡演示。
- [ ] **检索合同：** FTS5 中文 n-gram + normalize + MATCH escape + exact/LIKE 回退；`hit = 过滤后结果 ≥1`，永不垫假卡。

## 1. 最终技术方案（冻结）

### 1.1 一句话

**Electron + TS + React**；包甲 **单窗 Tab** + **sql.js** + **FTS n-gram** + **剪贴板主路径** + **seed**；同 `query_id` 进 Dashboard；自动填/better-sqlite3/真飞书/DeepSeek/向量 **全部后置且不得污染主叙事**。

### 1.2 架构（终态）

```text
electron-main
  IPC (zod) · clipboard · autofill-adapter(stub) · dialog
        │
        ▼
  services/*   ← 禁止 import 'electron'
    search | events | metrics | import | redaction | scripts-filter
        │
        ▼
  sqlite driver: sql.js (Package-A default)
                 better-sqlite3 (optional after Day0 gate)
renderer (single BrowserWindow @ 08-12)
  /float  |  /dashboard
产品终态：独立浮窗窗 + Dashboard 窗（同 services）
```

### 1.4 事件状态机（采纳 · 冻结）

```text
search → query_event (hit|no_hit) + impressions[0..3]
  hit:
    用户点选 rank k
      → push(clipboard|autofill)
         成功 → adoption{outcome=adopted, chosen_rank=k, push_method}
         失败 → adoption{outcome=dismissed 或独立 pending 策略：冻结为
                  outcome 不写 adopted；可写 push_method=failed 的 adoption
                  或 outcome=dismissed + push_method=failed}
         【冻结】分子只认 outcome=adopted ∧ push_method∈{clipboard,autofill}
    用户关闭无点选 → dismissed
  no_hit:
    空态 escalate 点击 → escalate_action
    离开 → no_hit_exit
```

**Demo 通过：** 至少一次 `push_method=clipboard` 成功；自动填失败不否决。

### 1.5 有效期过滤（P0 · 冻结）

```sql
-- 概念条件（实现于 services/scripts-filter）
status = 'published'
AND (effective_from IS NULL OR effective_from <= :now)
AND (effective_to   IS NULL OR effective_to   >= :now)
```

- Seed 活动价话术：**必须带** `effective_from/to` 覆盖演示日。\
- 另备 **1 条过期 seed** 仅用于单测「不得出现在 Top3」；**不进**演示主路径。\
- **禁止**环境变量关闭该过滤。

## 5. 仍做不到「组织 10 分」的唯一原因

设计/技术包按本文可到 **规格与包甲 10 分**。下列 **无法仅靠写代码/写文档闭合**，必须人做：

| 必须人做 | 说明 |
|----------|------|
| **ROLE-OWNER 业务签发** | 目标采纳率数值、活动话术权威口径、灰度名单 |
| **真实飞书库与权限** | OAuth、表结构所有权、手动同步源真相 |
| **安全/合规出域批** | 客户原话保留期、是否允许任何云 API、费用 B cap |
