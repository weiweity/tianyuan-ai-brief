## 2. R2 残余 P0 → v1.3 处置

| 洞 | 处置 |
|----|------|
| publish 仅 batch=新世界 | **MERGE**：prev ∪ staging，staging 覆盖同 id |
| 空 batch | COUNT ok &lt; 1 → VALIDATION |
| publishing 状态 | staged→publishing→published/回 staged |
| 幂等无 SQL | `idempotency_claim` / `idempotency_complete` |
| Retry-After | `rate_limit_take` 返回 `(allowed, retry_after_sec, tokens_left)` |
| 多桶顺序 | 同事务先 user 后 global，失败回滚 |
| v_scripts 扫 scripts | 视图改为 **content_current ⋈ release_items** |
| questions_json | 形状 + CSV 聚合规则（39） |
| canonical_json | JCS 子集规则（39） |
| HTTP 映射表 | 39 §0.5 |
| GRANT | 可粘贴完整 REVOKE/GRANT 段落（33） |
