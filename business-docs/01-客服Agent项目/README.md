## 阶段边界

需求阶段“已完成”表示项目侧基线已可供设计使用，不表示所有外部证据已齐。真实平台、内容 Owner、权威来源、指标基线和权限仍在 G0 台账补证。

当前门禁汇总：外部责任包 1/14、Scope 1/15（合计 2/29）。该数字由 `00–06` 真源约束，状态变化后必须重新生成并校验三视图。

设计阶段可做方案比较、低保真原型、ADR、数据模型、API 草案、评测与回退设计；不可编写或合并产品功能代码、部署、付费调用或承诺上线。
