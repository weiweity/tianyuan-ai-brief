## 真源分工

| 层级 | 内容 | 规则 |
|------|------|------|
| **业务真源（唯一）** | `00`～`06` | 状态、范围、排期、台账、费用、方法只在这里改 |
| **生成视图** | `07` PRD、`08` 执行中心、`09` 启动会主屏 | 由真源生成；**禁止直接维护状态** |
| **参考** | `80-参考/` | 沟通卡 / 模板；状态回链真源 |
| **评审证据** | `90-评审/` | 冻结评审与验证痕迹；**不能代替 `02` 台账** |
| **历史** | `99-历史/` | 只读旧稿；不得继续执行 |
| 组合优先级 | [`../00-项目驾驶舱.md`](../00-项目驾驶舱.md) | 组合级快照，细节回本目录 |

| 信息类型 | 唯一真源 | 更新触发 |
|----------|----------|----------|
| 项目目标、范围、里程碑 | 项目章程 | 范围、目标、阶段、里程碑改变 |
| 日期、门禁、资源基线 | 总排期 | 门禁或资源变化 |
| Owner、动作、证据、RAID、DEC / CR | G0 台账 | 事实、责任、风险或决定变化 |
| Scope、评测、验收 | Scope 与验收 | G0 冻结或正式评测 |
| 费用、cap、停止规则 | 费用与成本控制 | 预算或采购路径变化 |
| 技术工作流 | 全栈交付计划 | 架构 ADR、团队或发布方式变化 |

README、周报、汇报 Web 和历史材料都不能自行发明项目状态。
