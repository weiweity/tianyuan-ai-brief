## 8 月启动成功标准

1. **08-10** 启动会召开并有纪要；  
2. 书面：启动 / 有条件启动 / 不启动；  
3. 一件主事 + Owner + 日期；  
4. 样本或付费路径至少一条；  
5. 与客服分账表述清楚。
