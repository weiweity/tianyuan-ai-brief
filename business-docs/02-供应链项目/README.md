## 一句话

供应链 **备案查询** 线在 8 月做 **开好头**：把启动会开完、主事锁一件、责任到人；  
**不等于** 本月开发上线，也 **不等于** 与客服 Agent 共用进度表。

## 生命周期

| 阶段 | 状态 | 进入条件 |
|------|------|----------|
| 立项前准备 | **进行中（启动级）** | 启动会结论为启动或有条件启动；书面 Owner 与一刀口 |
| 需求 | 启动会后展开 | 明确业务 Owner、真实任务、权威来源与可验收指标 |
| 设计 | 未开始（沟通版约 08-19） | 需求基线签发；**独立** 设计包 |
| 开发 | 未开始 | **供应链独立 Ddev** 成立（不继承客服 Ddev） |
| 测试 / 发布 / 运营 | 未开始 | 按独立门禁推进 |

## 建议一刀口（默认）

| 项 | 内容 |
|----|------|
| 主事 | 备案文稿一致性：Excel 真源 ↔ 设计 / 备案稿 · AI 标疑 · **人终审** |
| 后置 | 法规细审、BOM 自动写入 SRM/金蝶（立项后） |
| 归 BI | 对账 / 预警类看板（FDE 不抢口径） |
| 红线 | 不承诺准确率%、全自动过审、智能排产 |

## 8 月启动成功标准

1. 启动会召开并有纪要；  
2. 书面结论：启动 / 有条件启动 / 不启动；  
3. 只锁定 **一件** 主事 + Owner + 日期；  
4. 样本或付费路径至少一条可执行；  
5. 与客服 **分账** 表述清楚。
