## 5. 必改 Top3（若要当场稳批 A）

1. **钱的锚一句（区间即可）**  
   例：「首期目标月 API cap 控制在可试用区间，超 cap 自动停；具体数与财务 3 日内回填。」  
2. **业务共签感**  
   若可能：客服负责人会前/会中口头原则同意一句，或你代述「已对齐待书面」。  
3. **口播删冗**  
   会上：〇 + 三句判断 + 选择 + 代价/收益 90″ + 费用勾选；访谈表只念姿态列。
