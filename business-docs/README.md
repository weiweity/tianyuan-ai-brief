## 公开仓与本地资料

- `business-docs/`：公开候选区；只有逐文件脱敏并通过 `DEC-PUBLISH-01` 后才可推送，禁止整目录默认公开；
- `local-private/`：仓内 **Git 发布隔离区**，已由 `.git/info/exclude` 排除；它不是文件系统物理隔离，也不承载当前私密项目或真实客户 PII；
- 需要真实姓名、客户原文、内部链接、精确费用或安全细节时，运行 `node business-docs/08-工具/prepare_private_customer_project.mjs --target=/仓外受控目录/客服Agent项目`，在仓外受控目录或公司受控系统维护；不让远程 README 指向私密实物。
