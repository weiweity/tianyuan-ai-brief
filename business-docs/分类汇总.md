## 卫生规则

- 新文档先判断：现行、参考、历史快照、兼容、归档还是生成物；
- 当前客服正文只进 `01-客服Agent项目/`；旧 `01-立项主线/` 不再产生新的现行文件；
- 原始纪要进 `03-调研与叙事/notes/` 并更新索引；
- 历史稿首屏必须写日期、失效原因和现行入口；
- 跨目录引用必须使用可点击链接；
- 迁移或交接前检查 Git 可见性；当前 `02`～`08` 受本地排除规则影响。
