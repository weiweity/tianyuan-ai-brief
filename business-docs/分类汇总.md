## 卫生规则

- 新文档先判断：现行、参考、历史快照、归档还是生成物。
- 现行状态只进指定真源；README 和周报只引用。
- 原始纪要进 [`03/notes/`](03-调研与叙事/notes/) 并更新索引；过程评审进 [`99-归档/`](99-归档/)。
- 历史稿首屏必须写日期、失效原因和现行入口。
- 迁移或交接前检查 Git 可见性；当前 `02`～`08` 受本地排除规则影响。
